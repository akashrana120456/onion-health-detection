Onion Health Checker - chalane ke steps

1. Python 3.9+ install hona chahiye.
2. Is folder me terminal kholiye aur chalaiye:
     pip install -r requirements.txt
     python app.py
3. Browser me kholiye:  http://localhost:5000
   (Same WiFi par phone se: http://<computer-ka-IP>:5000)

Model: best.pt (YOLOv8n-cls), accuracy 99.79% on 7091 images.
